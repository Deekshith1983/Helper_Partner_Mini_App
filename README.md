# Helper Partner Mini App

A simplified partner/helper application built as a hiring assessment for EzyHelpers.

## Project Architecture
- `backend/`: Django + Django REST Framework API with TokenAuthentication & SQLite.
- `mobile/`: Flutter (Android) application with Material 3 & Provider.

## Monorepo Layout
```text
.
├── backend/    # Python / Django REST API
├── mobile/     # Flutter Android client
└── README.md
```
